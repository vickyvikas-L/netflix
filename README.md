# 🎬 Netflix Clone

A **Netflix Clone website** created using only **HTML5 and CSS3**. This project is designed to recreate the look and layout of the Netflix homepage with a clean, responsive, and modern UI.

## 🚀 Features

* 🎬 Netflix-inspired homepage
* 🖼️ Hero section with background image
* 🔥 Trending movies and shows section
* 🌐 Language selection
* 🔐 Sign In button
* 📧 Email input and Get Started button
* ❓ Frequently Asked Questions section
* ⬅️➡️ Horizontal content layout
* 🎵 Audio integration
* 🌙 Dark Netflix-style theme
* 📱 Responsive design

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

> No JavaScript or backend is used in this project.

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/netflix-clone.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

Or use **Live Server** in VS Code.
